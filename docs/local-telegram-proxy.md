# Локальный прокси для аватарок

SFMap получает публичные страницы и фотографии Telegram через HTTP CONNECT, HTTPS CONNECT или SOCKS5. Внешний пул и локальный прокси на этом компьютере настраиваются отдельно.

В файле .env выберите режим:

~~~dotenv
TELEGRAM_TRANSPORT=proxy
TELEGRAM_PROXY_MODE=auto
TELEGRAM_LOCAL_PROXY_URL=http://127.0.0.1:8080
TELEGRAM_PROXY_FILE=./data/telegram-proxies.json
~~~

- external использует только внешний пул.
- local использует только локальный HTTP CONNECT / SOCKS5-прокси.
- auto использует локальный прокси и внешний резерв. Если локальный адрес не указан, используется внешний пул.

Локальный прокси должен быть уже запущен и поддерживать HTTP CONNECT, HTTPS CONNECT или SOCKS5. Например, TELEGRAM_LOCAL_PROXY_URL=socks5://127.0.0.1:1080. Разрешены адреса 127.0.0.1, localhost и ::1. Прокси применяется только к запросам страниц Telegram и их фотографий; административные запросы через него не идут. После изменения .env перезапустите SFMap.

Обновление внешнего списка и проверка полного цикла загрузки публичного фото:

~~~powershell
npm run proxies:refresh
npm run check:telegram
~~~

При сетевой ошибке сервер сохраняет прежнее фото и назначает повторную попытку через 15 минут. Если публичного фото нет, карта показывает инициалы.
