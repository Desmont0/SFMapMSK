# Справочник районов и населённых пунктов SFMap

Справочник shared/locations.json содержит 6 174 общие точки: 125 районов Москвы, 77 городских точек прежнего набора и 5 972 добавленных населённых пункта Московской области. Зеленоград, Троицк и Щербинка представлены едиными городами. Точки предназначены для ориентирования на карте сообщества, не показывают адрес участника и не являются кадастровыми центрами. Прежние 202 записи, включая их ID, названия и координаты, сохранены без изменений.

## Районы Москвы

Источник геометрии: GIS-Lab / © участники OpenStreetMap, через [Click That ’Hood, moscow.geojson](https://github.com/codeforgermany/click_that_hood/blob/main/public/data/moscow.geojson). [Метаданные источника](https://github.com/codeforgermany/click_that_hood/blob/main/public/data/moscow.metadata.json) указывают GIS-Lab/OpenStreetMap, http://gis-lab.info/qa/osm-adm.html. Данные OpenStreetMap распространяются под [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/); [атрибуция OpenStreetMap](https://www.openstreetmap.org/copyright).

Изменения: удалены отдельные районы Зеленограда; оставшимся присвоены стабильные ID и вычислены представительные точки внутри полигона. Сохранённая производная геометрия server/location-boundaries.json доступна в исходниках проекта на условиях ODbL. Исходные контуры датированы 2013 годом, применяются для переноса старых координат, не служат актуальным юридическим справочником границ.

Для Бекасово, Вороново, Коммунарки, Краснопахорского и Филимонковского добавлены условные центры. Внуково уже присутствует в исходном наборе. Троицк и Щербинка выбираются как города. Контуры Новой Москвы после реформы 2024 года не включены; при переносе старых точек вне сохранённых контуров используется ближайший центр Москвы.

## Города

Источник: [hflabs/city — Города России](https://github.com/hflabs/city), данные сервиса [DaData.ru](https://dadata.ru/). Названия, ФИАС-ID и координаты городов Московской области взяты из [city.csv](https://github.com/hflabs/city/blob/master/city.csv). Лицензия источника — [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), согласно README источника.

Изменения: выбраны города Московской области, включая центры, представленные в CSV как area_type=г; координаты округлены до 5 знаков. Производная часть справочника городов распространяется под CC BY-SA 4.0. Зеленоград, Троицк и Щербинка добавлены отдельно как общие условные точки.

## Населённые пункты Московской области

Источник — © участники OpenStreetMap, [региональная выгрузка OpenStreetMap France](https://download.openstreetmap.fr/extracts/russia/central_federal_district/moscow_oblast.osm.pbf). Время версии файла: 13 ноября 2026 года, 00:06:30 UTC. Размер PBF — 242 295 998 байт; MD5 — 4580d0a03a015f1152d393325814ce36, проверен по опубликованному файлу .md5. Производная часть справочника распространяется на условиях [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/); [атрибуция OpenStreetMap](https://www.openstreetmap.org/copyright).

Отобраны все именованные объекты с тегами place=city, town, village, hamlet или isolated_dwelling внутри сохранённой границы RU-MOS из public/geo/region.geojson. Из 6 025 точек исключены 74 уже представленных города; дополнительно включён 21 пункт, представленный только контуром. Дубли точки и контура устранены. Итого добавлено 5 972 записи. СНТ, микрорайоны, кварталы и урочища с другими тегами не включены. Данные могут содержать обезлюдевшие пункты, устаревшие названия или статусы: это набор OpenStreetMap, а не официальный государственный реестр.

Округа определены по 56 полным муниципальным контурам admin_level=6. Названия выбираются из name:ru или name, альтернативные названия из alt_name доступны в поиске. Тип пункта берётся из official_status; при отсутствии тега показано «Населённый пункт». Поисковые подсказки содержат название и округ. В 211 группах одноимённых пунктов внутри одного округа добавлен ближайший ориентир. Координаты округлены до пяти знаков; для контуров выбрана точка внутри полигона. ID имеют вид osm-node-<id>, osm-way-<id> или osm-relation-<id>.

В работе сайта обращения к источнику не нужны: справочник поставляется вместе с приложением. Полный файл загружается только с админкой. В SQLite хранятся выбранный ID и данные анкеты; расширение справочника не меняет схему базы и не требует переноса пользователей.

## Воспроизведение

Исходники районов и городов получены 11 ноября 2026 года. Скрипт scripts/build-locations.ts читает data/location-districts-source.json и data/location-cities-source.csv либо загружает их из указанных репозиториев, затем пересобирает исходные записи в shared/locations.json и server/location-boundaries.json. Уже импортированные записи с префиксом osm- сохраняются. Для запуска: node --import tsx scripts/build-locations.ts.

Для импорта населённых пунктов подготовьте GeoJSON через osmtogeojson из регионального PBF: нужны точки и полные контуры с перечисленными тегами place, а также полные муниципальные границы admin_level=6 со всеми вложенными линиями и узлами. Поддерживаются теги в properties.tags и плоские properties. Сохраните промежуточный файл вне Git, например в data/osm-places.geojson, и выполните:

    node --import tsx scripts/import-settlements.ts data/osm-places.geojson
    npm run build
    npm test

Импорт проверяет границу региона, наличие округа, уникальность ID и подписей, отбрасывает неполные полигоны и защищает от случайной записи сильно урезанного источника. Исходные 202 записи сохраняются, а записи osm- пересоздаются; повторный запуск с тем же входным файлом даёт тот же результат. В выгрузке другой даты число записей и названия могут отличаться. Перед публикацией обновлённого источника проверяйте сохранность используемых ID.
